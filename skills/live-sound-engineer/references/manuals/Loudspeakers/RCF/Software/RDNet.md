# RCF RDNet

RCF's network control, monitoring and DSP platform for HDL, TT+ and SUB series (level, delay, EQ incl. FiR linear phase, limiter/temperature/transducer monitoring, Easy Shape Designer, Bass Shaper). Prediction is RDShape, which is restricted to certified TT+ Audio GTX users (no public download) — use EASE Focus 3 + the GLL files otherwise.
