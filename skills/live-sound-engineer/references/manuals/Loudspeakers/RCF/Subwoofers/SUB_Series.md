# RCF SUB Series Active Subwoofers

Ground-stack active subwoofers. All have onboard DSP with selectable crossover presets; the 8008-AS and 9019/9029-AS add onboard cardioid presets. Use the Pre-Alignment Delays sheet on each RCF top's page to time-align tops to these subs. Several manuals cover more than one model (same Doc No.).
