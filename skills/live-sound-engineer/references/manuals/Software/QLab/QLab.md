# Figure 53 QLab

## Overview

QLab is a live media playback and show control program for macOS. Its design is based around concepts and conventions of the theatrical, broadcast, and cinematic industries.

## Key Features

### Audio
- Audio cue playback and routing
- Mic cues for live input
- Fading and audio effects
- Audio patch editor

### Video
- Video cue playback
- Camera cues
- Text cues
- Video surfaces and effects
- NDI support

### Lighting
- Light cues
- Light Dashboard
- Lighting Command Language
- Light Patch Editor
- Light Library with instrument definitions

### Show Control
- QLab Remote (iOS app)
- Stream Deck support
- OSC (Open Sound Control)
- MIDI and MSC (MIDI Show Control)
- Timecode (MTC and LTC)
- Network cues
