# Shure Wireless Workbench (Complete Guide)

## Overview

Wireless Workbench (WWB) is Shure's free device management, frequency coordination, and RF monitoring software. Using Wireless Workbench, you can analyze, calculate, and deploy frequencies to your devices based on available scan data.

## Key Features

### Frequency Coordination
- Analyze frequency compatibility
- Calculate compatible frequencies
- Deploy frequencies to devices
- Plan backup frequencies

### RF Monitoring
- Real-time RF level monitoring
- Spectrum scanning
- Interference detection and management
- AD600 Live Plot support

### Device Management
- Inventory management
- Device properties and settings
- Custom equipment profiles
- Show files and show packs

### Scan Library
- Online database of RF scans
- Upload and download scans
- Community-driven scan data

## Network Requirements

- Ethernet network connection
- CAT5 or better Ethernet cable
- Router or switch recommended for multiple devices
- Automatic (DHCP) or manual IP addressing
