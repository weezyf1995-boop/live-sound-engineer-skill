# d&b audiotechnik R1 Remote Control Software

## Overview

R1 Remote control software enables d&b devices to be remotely controlled, using both Ethernet and CAN-Bus. It is optimized for use with touchscreen, mouse and keyboard and runs on Microsoft Windows and macOS operating systems.

## System Requirements

### PC
- 1.5 GHz (higher recommended)
- Windows 10 or later
- 4 GB RAM (8 GB recommended)
- 1280 x 800 or higher screen resolution
- Wired ethernet connection

### CAN Interfaces
- R60 USB to CAN interface (for CAN-only amplifiers: D6, D12, E-PAC)
- R70 Ethernet to CAN interface
